# NutriPlan 🥗

NutriPlan is a responsive nutrition web application that helps users discover meals, view detailed recipes and nutrition information, scan food products, and track their daily food intake.

## Features

* 🍽️ Browse and search meals
* 🔍 Filter meals by category and cuisine
* 📋 View detailed recipes, ingredients, instructions, and video tutorials
* 🥗 Analyze and display nutrition information
* 📊 Track daily nutrition and logged meals
* 📅 Weekly nutrition overview
* 📱 Fully responsive design for different screen sizes
* 💾 Food Log data stored using LocalStorage

## Technologies

* HTML5
* Tailwind CSS
* JavaScript (ES6+)
* REST APIs
* LocalStorage
* Font Awesome
* SweetAlert2
* Plotly.js

## APIs

* TheMealDB
* NutriPlan API
* USDA FoodData Central
* OpenFoodFacts

A responsive JavaScript-based nutrition application built as a practical project to apply API integration, DOM manipulation, LocalStorage, and modern frontend development concepts.
